# SubTrack — Subscription Management System

A lightweight subscription management dashboard built for the **Odoo x Make-A-Ton 9.0 Kochi Hackathon 2026**.

## Problem
People and small teams often lose track of recurring subscriptions, renewal dates and cumulative spending. SubTrack brings those details into one simple dashboard.

## MVP Features
- Add and manage subscriptions
- Track monthly/yearly billing
- Active / paused / cancelled status
- Upcoming renewal tracking
- Monthly and yearly recurring-spend calculation
- Category-wise spending visualization
- Search and filter subscriptions
- Local browser storage for persistence
- Responsive dashboard

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## Run locally
Open `index.html` in a browser.

## Demo flow
1. Open Dashboard.
2. Show monthly spend, active subscriptions and upcoming renewals.
3. Go to Subscriptions.
4. Add a new subscription.
5. Search/filter it.
6. Show Analytics and category spending.
7. Explain how the same workflow can be integrated with an Odoo backend/module for production.
